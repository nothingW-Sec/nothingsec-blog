# thinking

```yaml
要明白一个事实，学习不是记忆而是总结和归纳

把信息压缩成了可迁移的模型

知识框架真正的价值——它不是让你记住更多，而是让你需要记住的更少
```

```yaml
一套完整的逻辑
	1.怎么进行工作的
	2.为什么要这样进行设计
	3.出错了会造成什么后果
	4.在整体的哪个位置
	5.属于什么深层的问题
	6.替代方案
```

1. 原理：工作的机制是什么
2. 设计：问什么要这样设计
3. 架构：在整个系统的什么位置，上游和下游是什么
4. 故障：坏了会发生什么，影响了整个系统的什么
5. 本质：技术解决的问题真正是什么
6. 边界：技术的范围，能解决什么问题，不能解决什么问题
7. 替代：有什么其他的方案
8. 验证：怎么进行启用来证明他是真正工作的
