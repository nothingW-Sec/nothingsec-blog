在现在的公司企业网络的配置信息里面，位于网络层中的主要的设备是路由器，路由器的作用就是路由，根据路由表查看想要到达目标IP的下一跳是什么，路由器的一个重要部分就是路由表，路由表的内容的来源有三，一个是静态路由，由管理员进行手动添加，缺点是当设备超过三个时配置就开始复杂起来。二个是动态路由，动态的路由基于动态路由协议OSPF，OSPF的内容是在一个area区域内的设备进行交换路由的信息，最后每个路由器得到得到整个网络的拓扑图。三个是默认路由，默认路由的主要的作用是出网，常用的IP是0.0.0.0/32。在vlan局域网中有特殊的路由方式，一个是由三层交换机这个设备实现的vlanif技术，先将接口加入vlan内，再启用vlanif这个功能并配置IP地址，并将这个IP地址作为该vlan的网关。另一个方式则是用路由器自带的单臂路由，是dot1q，即直接在端口号后面跟上小数位并跟上IP地址作为该vlan的网关。MAC地址解析协议ARP是一个极其重要的协议，只要一个网络设备涉及转发，都离不开ARP协议，ARP协议的内容是根据IP解析出对应的MAC地址。

来到第二层数据链路层，这里的核心设备是交换机，交换机的核心作用是转发根据mac地址转发数据帧。与交换机有关的技术有生成树协议STP，生成树协议解决的问题是在链路层中的数据环路问题，当多个交换机连接在一起时可能形成数据环路使得数据包一直在链路中进行传递。STP协议的内容是先根据优先级决定根桥，再以根桥为书的根部，结合每一条链路的COST找到到达目的最小的cost线路，将其他的链路暂时关闭作为备用的链路。与交换机有一个重要的技术是虚拟局域网技术VLAN，将整个网络划分成多个逻辑网络区域，作用是提高安全性和减少广播的影响。对于vlan的划分有集中方法，一种是根据端口进行划分，先启用valn再进入端口进行操作，将端口划分进一个valn里面。第二种是根据MAC地址进行划分，将具体的mac划分进一个vlan里面。提到vlan就必须提到端口的连接方式，有三种端口的连接方式，一种是access连接，这种连接一般用于主机与交换机之间的连接，只允许连接相同的vlan，一种是trunk接口，常用于连接两个路由器之间，也常用于链路聚合技术。第三种是Hybrid接口。还有一个链路聚合技术eth-trunk，目的是提高是将多个端口在逻辑上面连接在一起从而提高带宽，通常使用的是trunk接口 。

在企业网络架构中，网络层（三层）的核心设备主要是路由器和三层交换机。路由器的主要作用是实现不同网络之间的数据转发，当路由器收到一个数据包后，会根据目标 IP 地址查询路由表，确定到达目标网络的最佳路径以及下一跳设备，然后将数据包转发出去。路由表是路由器实现转发的核心，其来源主要包括直连路由、静态路由、动态路由和默认路由。直连路由是设备接口配置 IP 地址并正常工作后自动生成的路由；静态路由由管理员手动配置，优点是路径可控、配置简单，但随着网络规模扩大，维护难度会增加；动态路由则通过动态路由协议自动学习网络信息，例如 OSPF、IS-IS、BGP 等。其中 OSPF 是一种链路状态路由协议，在同一个 Area 区域内，路由器之间通过交换 LSA（链路状态通告）信息建立 LSDB（链路状态数据库），从而获得整个网络拓扑结构，再通过 SPF 算法计算最佳路径，并生成路由表。默认路由主要用于访问未知目标网络，企业网络中通常用于互联网出口，其地址表示为 IPv4 的 0.0.0.0/0，表示可以匹配所有目标网络。当局域网中存在多个 VLAN 时，不同 VLAN 默认属于不同广播域，无法直接通信，需要通过三层设备实现 VLAN 间路由。常见方式有两种，一种是三层交换机的 VLANIF 技术，通过创建 VLANIF 逻辑接口并配置 IP 地址，将该地址作为对应 VLAN 的默认网关，实现不同 VLAN 之间的数据转发；另一种是单臂路由技术，通过在路由器一个物理接口上创建多个逻辑子接口，并使用 802.1Q 协议携带 VLAN Tag 区分不同 VLAN，每个子接口配置 IP 地址作为对应 VLAN 的网关，实现 VLAN 间通信。ARP（地址解析协议）用于根据 IP 地址解析对应的 MAC 地址，但它并不是所有网络转发过程都必须使用，而主要用于同一局域网内获取目标主机 MAC 地址，或者跨网段通信时获取下一跳网关的 MAC 地址。

在数据链路层（二层）中，核心设备主要是交换机。交换机的主要作用是根据 MAC 地址表对数据帧进行转发。当交换机收到数据帧后，会首先学习源 MAC 地址，并将其与进入接口建立映射关系，然后根据目标 MAC 地址查询 MAC 地址表，选择对应接口转发数据。交换机中的重要技术包括 STP、VLAN、Eth-Trunk 和接口类型等。STP（生成树协议）主要解决二层网络中的环路问题，当多个交换机通过冗余链路连接时，可能形成网络环路，导致广播风暴和 MAC 地址表震荡。STP 会首先根据 Bridge ID（由优先级和 MAC 地址组成）选举根桥，然后以根桥为参考，根据链路 Cost 计算最佳路径，将不必要的冗余链路接口置于 Blocking 状态，从而避免环路，同时保留备用路径。VLAN（虚拟局域网）是一种二层逻辑隔离技术，可以将一个物理网络划分为多个逻辑广播域，从而减少广播影响并提高网络安全性。VLAN 常见划分方式包括基于端口划分 VLAN 和基于 MAC 地址划分 VLAN，其中基于端口的 VLAN 是企业网络中最常见的方式。为了实现 VLAN 数据在不同交换设备之间传输，需要使用不同类型的接口。Access 接口通常用于连接终端设备，只属于一个 VLAN，并且一般不携带 VLAN Tag；Trunk 接口通常用于交换机之间连接，可以同时传输多个 VLAN 的数据，并通过 802.1Q Tag 区分不同 VLAN；Hybrid 接口是部分厂商设备提供的特殊接口类型，可以灵活处理 Tagged 和 Untagged 数据。Eth-Trunk 是链路聚合技术，它可以将多个物理接口绑定成一个逻辑接口，提高链路带宽和可靠性，常用协议为 LACP。

因此，在学习企业网络设备时，提到路由器应该联想到 IP 协议、路由表、直连路由、静态路由、动态路由协议（OSPF、IS-IS、BGP）、默认路由、ARP、NAT、ACL、单臂路由等内容；提到交换机应该联想到 MAC 地址表、VLAN、STP、Eth-Trunk、Access/Trunk/Hybrid 接口以及三层交换中的 VLANIF 技术。从数据流角度来看，一个数据包在网络中的传输过程是：应用层产生数据，传输层通过 TCP/UDP 确定通信端口，网络层通过 IP 地址确定目标网络，设备根据路由表选择下一跳，通过 ARP 获取下一跳 MAC 地址，然后交换机根据 MAC 地址完成二层转发，路由器根据 IP 地址完成三层转发，最终数据到达目标网络并交付给目标主机。
